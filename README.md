# Python-Project-50

Краткое описание проекта, его назначения и ключевых функций.

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/AnatoliySigutin/python-project-50#

2. Перейдите в проект:

cd python-project-50

3. Создайте виртуальное окружение:

python -m venv venv
source venv/bin/activate

4. Установите зависимости:

uv install

5. Запуск тестов:

pytest
